# 維度邊境（Pixel Odyssey 2D）

以原生 HTML、CSS 與 JavaScript 製作的 2D Canvas 動作遊戲。玩家在 1D 與 2D 維度間切換，探索地圖、解謎、挑戰 Boss，並逐步解鎖後續周目。

## 開始遊玩

專案不需要安裝套件或建置。建議在專案目錄啟動本機伺服器：

```powershell
python -m http.server 8000
```

用瀏覽器開啟 `http://localhost:8000`，按「開始新遊戲」。若電腦沒有 Python，也可以直接開啟 `index.html`；但瀏覽器對本機檔案的儲存權限可能不同。遊戲支援鍵盤與畫面下方的觸控按鈕。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| `A` / `D` | 左右移動 |
| `W` / `S` | 在 2D 維度上下移動 |
| 滑鼠左鍵 | 攻擊；舉盾時可盾反 |
| `E` | 舉盾、反震敵人 |
| `C` | 切換到 2D 維度，持續 10 秒；返回 1D 後冷卻 5 秒 |
| `F` | 與 NPC 對話、開門、使用商店 |
| `G` | 靠近商人時開啟賭桌 |
| `R` | 使用生命藥水 |
| `T` / `Q` | 使用狂戰藥水／星塵炸彈 |
| `Z` / `B` | 使用解謎羅盤／護盾晶核 |
| `P` | 暫停或繼續 |
| `X` | 一般關卡重新開始；競技場離開；電梯從第 1 波重試 |

## 周目與競技場

1. **一周目**：向老人學習操作，通過十一張地圖與解謎。通關後進入二周目。
2. **二周目**：敵人與 Boss 增強。前往維度核心擊敗「維度之源」後，回歸之門會遭作者鎖上；擊敗作者才能返回正常世界。
3. **三周目**：從競技場休息室的中央門開始挑戰。競技場有 50 波，每波依序出現 5 名敵人；每第 5 波再打 1 名 Boss，第 50 波是最終 Boss。敵人與 Boss 隨波次變強。休息室可與挑戰者對話、向商人補給。競技場死亡會回到起始休息室，保留裝備、金錢與最高完成波次。
4. **四周目**：擊敗競技場最終 Boss 後會播放作者與挑戰者的劇情，接著在上升電梯中打完 5 波、每波 5 名敵人。抵達頂端後回到主選單，選擇「進入四周目」。解鎖後主選單選項會抖動。

## 密技

先點擊遊戲畫面取得控制權，再依序輸入以下按鍵，不需要按 Enter：

| 按鍵序列 | 效果 |
| --- | --- |
| `AAWWDDSS` | 前往二周目 |
| `DDDWWWAAASSSAWDS` | 抵達競技場休息室的三周目之門 |
| `AWDSAWDSAWDS` | 直接前往競技場第 50 波 |
| `AWDSSDWASSDWASSADWSS` | 獲得 200,000 金幣；需在遊戲畫面中輸入 |

## 存檔與測試

遊戲進度會定期儲存在瀏覽器的 `localStorage`，也會在部分關卡轉換時儲存。可用畫面上的「讀取進度」與「清除存檔」按鈕管理進度；清除存檔也會清除四周目解鎖狀態。

若已安裝 Node.js，可在專案目錄執行流程測試：

```powershell
node arena.test.js
```

測試涵蓋競技場 50 波、敵人與 Boss 輪替、挑戰者對話、休息室商人、劇情、電梯、四周目、密技，以及存讀檔與死亡重試。

## 專案檔案

- `index.html`：遊戲選單、控制項與 Canvas。
- `style.css`：介面樣式與四周目選單動畫。
- `game.js`：遊戲狀態、戰鬥、地圖、劇情與存檔。
- `arena.test.js`：使用 Node.js 執行的流程測試。
