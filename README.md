# 維度邊境（Pixel Odyssey 2D）

以原生 HTML、CSS 與 JavaScript 製作的 2D Canvas 動作遊戲。玩家在 1D 與 2D 維度間切換，探索地圖、解謎、挑戰 Boss，並逐步解鎖後續周目。

## 開始遊玩

專案不需要安裝套件或建置。建議在專案目錄啟動本機伺服器：

```powershell
python -m http.server 8000
```

用瀏覽器開啟 `http://localhost:8000`，按「開始新遊戲」。若電腦沒有 Python，也可以直接開啟 `index.html`；但瀏覽器對本機檔案的儲存權限可能不同。手機或平板可在同一個區域網路中開啟電腦的網址（例如 `http://電腦的區網 IP:8000`），建議橫向遊玩。

手機與平板會顯示螢幕控制：左側方向鍵可持續移動，右側可舉盾、攻擊、切換維度及互動。點「道具與選單」可使用道具、開商店與賭桌、儲存／讀取進度、暫停、重新開始及進入全螢幕。直向時按鈕移到遊戲畫面下方。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| `A` / `D` | 左右移動 |
| `W` / `S` | 在 2D 維度上下移動 |
| 滑鼠左鍵 | 攻擊；舉盾時可盾反 |
| `E` | 舉盾、反震敵人 |
| `C` | 切換到 2D 維度，持續 10 秒；返回 1D 後冷卻 5 秒 |
| `F` | 與 NPC 對話、開門、使用商店 |
| `H` / `G` | 開啟商店／賭桌；四周目取得倖存者能力後可隨時使用 |
| `R` | 使用生命藥水 |
| `T` / `Q` | 使用狂戰藥水／星塵炸彈 |
| `Z` / `B` | 使用解謎羅盤／護盾晶核 |
| `P` | 暫停或繼續 |
| `X` | 一般關卡重新開始；電梯從第 1 波重試 |

## 周目與競技場

1. **一周目**：向老人學習操作，通過十一張地圖與解謎。通關後進入二周目。
2. **二周目**：敵人與 Boss 增強。前往維度核心擊敗「維度之源」後，回歸之門會遭作者鎖上；擊敗作者後直接抵達競技場休息室。
3. **三周目**：從競技場休息室的中央門開始挑戰。競技場有 30 波，每波依序出現 5 名敵人；每第 5 波再打 1 名 Boss，第 30 波是最終 Boss。敵人與 Boss 隨波次變強。休息室可與挑戰者對話、向商人補給。競技場死亡會回到起始休息室，保留裝備、金錢與最高完成波次。
4. **四周目**：擊敗競技場最終 Boss 後，作者現身說「你以為你能殺死我？」；挑戰者把主角推進上升電梯，留下來獨自面對作者。電梯有 5 波、每波 5 名敵人，頂端的光照下後直接從第一世界起點開始四周目。主選單沒有四周目專用入口；離開遊戲後用「讀取進度」繼續。四周目擊敗維度核心的異變作者後直接進入五周目競技場。
5. **五周目**：從感染的競技場休息室開始。競技場背景、敵人和 Boss 都受到感染，休息室的挑戰者、商人等 NPC 消失，無法在競技場交易或賭博。玩家重新挑戰 30 波；擊敗第 30 波 Boss 後，挑戰者以「競技場真・最終 Boss」身分現身，施展連拳、掃腿、飛踢、氣勁，以及強力的龍牙連掌、震地崩拳。擊敗他後，挑戰者恢復正常並與主角重逢；感染世界的幕後黑手 bag 現身，把挑戰者打進電梯，再將主角拉進全黑房間宣戰。bag 會使用腐蝕扇擊、感染十字、暗黑脈衝，以及感染牢籠、終蝕彈幕。挑戰者有 170 HP，bag 有 194 HP；強招有預警與較長恢復時間。劇情和戰鬥進度可存檔，死亡後從起始休息室重來。

擊敗 bag 後，主角回到正在坍塌的競技場，與挑戰者一起被倖存者救下。世界恢復色彩，挑戰者說「我們是最強的！」；前方出現回家的門，主角與朋友們道別後穿門回到正常世界，畫面顯示「劇終」。結局各段都可存讀檔；舊版已擊敗挑戰者或 bag 的存檔會接續對應的新劇情。

四周目的所有敵人與 Boss 都受到神秘物質感染，攻擊與生命值提升，外型與場景也改變。老人和普通商人消失；感染商人會攻擊，無法交易或賭博。擊敗感染商人後，從原商人位置進入洞穴，與倖存者對話即可取得隨時開啟商店及賭桌的能力。洞穴與倖存者的進度可存檔。四周目的遺跡符文順序改為「日 → 星 → 月」，寒霜印記與後續地圖的解謎規則也會改變。

敵人與 Boss 各有自己的攻擊節奏及軌跡；同類型攻擊也會在預警時間、落點、彈幕數量和速度上有所差異。競技場不顯示離開按鈕，死亡後會自動返回起始休息室。

四周目進入維度核心、開始與作者對話時，作者會受神秘物質感染變身並獲得新力量。戰鬥增加垂直裂隙與雙側虛影兩種有預警的新招式；二周目的作者維持原本招式。

## 世界謎題

| 世界 | 解法 |
| --- | --- |
| 1 維度邊境 | 擊敗 Boss 後收集維度碎片。 |
| 2 遺跡 | 依牆上日、月、星的提示點亮符文。 |
| 3 核心聖堂 | 踩印記會切換自己與相鄰印記，讓三枚同時亮起。 |
| 4 冰封裂谷 | 依指定順序取得三枚寒霜印記；四周目順序改變。 |
| 5 虛空王座 | 擊敗虛空君王後，進入 2D 並站在錨點內 3 秒。 |
| 6 星塵荒原 | 任選第一枚星核，第二枚需選距離最遠的，最後選剩下的；四周目改選最近的。 |
| 7 齒輪深窟 | 踩踏會同時轉動自己與下一座齒輪，讓四座刻度一致。 |
| 8 潮汐墓園 | 限時點亮四盞潮燈，順序不限。 |
| 9 赤焰高原 | 反覆踩踏符文調整刻度，讓三個刻度符合提示。 |
| 10 時鐘盡頭 | 按跨時針路線觸碰五枚時輪。 |
| 11 終焉核心 | 兩兩配對六枚核心。 |

維度核心的回歸之門則由劇情控制：擊敗維度之源可開門，但作者會現身鎖門；擊敗作者後才能離開。四周目的各世界提示會直接顯示新的順序、目標刻度或配對方式。

## 密技

先點擊遊戲畫面取得控制權，再依序輸入以下按鍵，不需要按 Enter：

| 按鍵序列 | 效果 |
| --- | --- |
| `AAWWDDSS` | 前往二周目 |
| `DDDWWWAAASSSAWDS` | 抵達競技場休息室的三周目之門 |
| `AWDSAWDSAWDS` | 直接前往競技場第 30 波 |
| `DWASDWASDWAS` | 直接前往五周目感染競技場第 30 波 |
| `AWDSSDWASSDWASSADWSS` | 獲得 200,000 金幣；需在遊戲畫面中輸入 |

## 存檔與測試

遊戲進度會定期儲存在瀏覽器的 `localStorage`，也會在部分關卡轉換時儲存。可用畫面上的「讀取進度」與「清除存檔」按鈕管理進度；清除存檔也會清除舊版四周目入口的紀錄。

若已安裝 Node.js，可在專案目錄執行流程測試：

```powershell
node arena.test.js
```

測試涵蓋競技場 30 波、敵人與 Boss 輪替、挑戰者對話、休息室商人、劇情、電梯、四周目感染商人與洞穴、作者新招式、五周目競技場、各世界謎題、觸控操作、密技，以及存讀檔與死亡重試。

## 專案檔案

- `index.html`：遊戲選單、控制項與 Canvas。
- `style.css`：介面樣式與手機、平板操作配置。
- `game.js`：遊戲狀態、戰鬥、地圖、劇情與存檔。
- `arena.test.js`：使用 Node.js 執行的流程測試。
